# Font attribution

The typefaces bundled here are **IBM Plex Sans**, **IBM Plex Sans Condensed**
and **IBM Plex Mono**, copyright IBM Corp., released under the
**SIL Open Font License 1.1**.

They are redistributed with this project so the web edition renders identically
offline and the PDF embeds correctly with no network fetch. The OFL permits this
provided the licence travels with the fonts.
